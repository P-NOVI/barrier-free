# barrier-free

배리어프리 프로젝트입니다.

## 시작하기

```bash
git clone https://github.com/P-NOVI/barrier-free.git
cd barrier-free
```

## 커밋 컨벤션

`<gitmoji> <type>: <내용>` 형식을 따릅니다.

| 타입 | 설명 |
| --- | --- |
| feat | 새로운 기능 추가 |
| fix | 버그 수정 |
| docs | 문서 수정 |
| style | 코드 포맷 변경, 세미콜론 누락, 코드 변경 없음 |
| refactor | 프로덕션 코드 리팩터링 |
| test | 테스트 추가, 테스트 코드 리팩터링, 프로덕션 코드 변경 없음 |
| chore | 빌드 태스크 업데이트, 패키지 매니저 환경설정, 프로덕션 코드 변경 없음 |
